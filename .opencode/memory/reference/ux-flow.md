# UX flow reference (read on demand for Phase 2 tasks; not auto-loaded)
Shell: no bundler, hash router in web/app.ts. Routes: #/, #/review/:deckId, #/deck/:id, #/quizzes, #/quiz/:id, #/attempt/:id, #/grading, #/stats. Import is a modal (openImport()), not a route. Desktop left rail + mobile bottom nav (Home, Quizzes, Grading, Stats); header has Import, shortcuts dialog (?), theme toggle (localStorage + prefers-color-scheme). ?mock=1 swaps web/api.ts for web/api.mock.ts. Views export mount(el, ctx) and return an optional cleanup fn. Review enters focus mode; all other views clear UI context ({view:null}).
Home: greeting, total-due line, CTA to #/review/<deck with most due>, per-deck meters (total/mature/learning/due), linked-quiz chip, rename/create deck dialogs; aside: "N answers awaiting grading" banner, 14-week heatmap, recent attempts (in-progress -> #/quiz/:id, finished -> #/attempt/:id). Refreshes from SSE (deck/card/attempt/answer/review), batched ~400-550ms.
Deck: browse/search/filter cards (source markers user/ai/import), Markdown+LaTeX editing toolbar, manual due-time override (shift minutes, due now, ignore), linked quiz chip, destructive delete with name confirmation.
Review: full-screen flashcard; default deck = most due. Space reveals; 1-4 rate Again/Hard/Good/Easy with interval previews from srs.preview(); U undo (global), Esc exits. Session-complete / all-caught-up states. Reports ui_context on every card/flip.
Quizzes/Quiz/Attempt: overview (question count, points, shuffle toggle, AI-made chip, linked deck, start/restart attempt); one question at a time (A-H choices, left/right navigate, Cmd/Ctrl+Enter submit, flag questions); results show Correct/Incorrect/Partial/"Awaiting AI" per answer.
Grading: queue of short/latex responses with prompt, student response, model answer, rubric; copy says AI grades via MCP; manual form is the fallback; updates live.
Stats: totals, reviews/day heatmap, retention, interval distribution (new/learning/mature), weakest tags.
Import modal: copy IMPORT_PROMPT into another assistant, paste back one JSON bundle (fenced ```json stripped); importBundle validates everything before writing (atomic), reuses same-name decks, max 50 decks/50 quizzes, one quiz per deck; fires synthetic live:change.
Content: every text field is Markdown + KaTeX; web/math.ts is the single untrusted-text->DOM boundary (raw HTML escaped, links http(s)/mailto only). Never bypass it.
Native-feature hooks: due counts come from the review queue/deck summaries; deep links map to the hash routes above; notifications can key off SSE changes (answer graded, cards due).
